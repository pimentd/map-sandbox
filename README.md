## Technical Notes

- Written in **vanilla JavaScript** (no frameworks)
- Uses:
  - SVG event delegation for performance
  - Web Speech API for pronunciation
  - Web Audio API for sound effects
  - `requestAnimationFrame` for smooth timers and animations
- Optimized for:
  - Fast startup
  - Low memory usage
  - Clean separation of logic and UI

---

## Customization

To modify quiz content:

- **Add/remove countries**: edit the `COUNTRIES` array in `app.js`
- **Disable small islands**: update `DISABLED_ISLANDS`
- **Change regions**: adjust each country’s `region` field
- **Pronunciation overrides**: add entries to `PRONUNCIATION`
